# Dexter Eco System — dexterecosystem.github.io

Публичный сайт экосистемы **Dexter Eco System (DES)** — от цели к результату через индивидуальную систему развития.

Страница: https://dexterecosystem.github.io/

## Содержимое репозитория

- `index.html` — единственная страница сайта (статический HTML/CSS, без сборки).

## О системе

DES связывает цель человека, нужные для неё навыки, текущий уровень и доступное время
и превращает это в ежедневные действия с измеримым результатом.

Направления: Dexter Typing (первый продукт), Dexter English, Dexter AI Engineering, Dexter Productivity.

## Локальный просмотр

Открыть `index.html` в браузере или поднять статический сервер:

```
python -m http.server 8000
```
